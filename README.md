LAB 7 - Galerie de Stars
Application Android native en Java pour afficher une galerie de personnalites celebres.

Fonctions implementees :

liste avec RecyclerView ;
adapter personnalise et pattern ViewHolder ;
images circulaires chargees depuis Internet avec Glide ;
notes visuelles avec etoiles colorees ;
animations d'introduction de la liste ;
filtrage dynamique par nom avec SearchView.
Lancer
Ouvrir ce dossier dans Android Studio, puis lancer l'application.

Depuis PowerShell :

.\gradlew.bat assembleDebug
